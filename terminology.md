# Terminology

Q. What is the statement?
- A statement is the command that tell computer to do something.

Q. What is the expression?
- An expression is a value or something that can be calculated as a value.

Q. What is keyword?
- A keyword is the special reserved word in the programming language. That you can't use for your self while you are writing the code.

Q. What is identifiers?
- An identifiers is a name that given by programmer to define the variable, function, classes etc.

Q. What if variable is inside a class?
- Variable inside a class known as a fields, properties
